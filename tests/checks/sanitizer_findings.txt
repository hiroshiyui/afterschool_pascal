# It arrived with one entry -- `pas_bind` copied the external name a file
# variable was bound to, `pas_file_done` never freed it, and a program that
# binds repeatedly leaked a name each time. `lsp/pasls.pas` binds once per
# document write, which is once per keystroke in an editor, so the one program
# here that runs for hours was the one paying. It is fixed: one `free` in
# `pas_file_done`, before the early return the standard files take.
#
# What is worth keeping is why no other oracle could see it. `heap-balance`
# tallies `pas_new` against `pas_dispose` and the runtime has more allocators
# than one -- ADR-0183's own record says so, in the sentence "It counts no
# files and no handles", which nobody had tested. This gate is what tests it.
