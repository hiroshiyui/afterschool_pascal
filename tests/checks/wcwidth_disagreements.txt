# Why AP 6.4.15.13's table and a C library's `wcwidth` may differ (ADR-0398).
#
# **This is a list of causes and not a list of code points, and the first
# version of it was the second kind.** That version was taken on one machine,
# passed there, and failed on macOS and on ubuntu:24.04 -- because an
# enumerated range list is a fact about *that* C library's table and not about
# this one. Two libraries built from the same database differ in exactly the
# places the database leaves open, and every one of those places has a name.
#
# So what is required is that every disagreement fall into a cause below, and
# each cause is a **property of the code point** that this tree already holds a
# table for. A disagreement that fits none of them is the transcription error
# this gate exists to find.
#
# One field per line: the cause, then the Grapheme_Cluster_Break values that
# select it, or `-` where the rule is not about a break class.
#
# cluster: a code point that is not a base of its own -- a control, a format
#   character, a combining mark, a joiner, a prepended sign. AP 6.4.15.13 b)
#   gives Cf and Cc no cell and gives a spacing mark one; a library that
#   measures code points has to decide the same question with no cluster to
#   hang the answer on, and they decide it differently. glibc gives a soft
#   hyphen one cell; the C library on macOS gives a Devanagari matra none.
#   Neither is wrong about a *value*, because the value is measured by element.
cluster   CR LF Control Extend ZWJ Prepend SpacingMark
#
# jamo: a conjoining Hangul jamo, and **the two agree about every text and
#   disagree about every code point**. `wcwidth` is per code point, so it gives
#   a leading jamo two cells and a medial and final none, summing to two for a
#   syllable. AP 6.4.15.13's unit is the element, and UAX #29's GB6, GB7 and
#   GB8 put L, V and T in one cluster -- so the syllable is one element of two
#   cells and the parts are never measured alone. Probed: `Columns` of
#   U+1100 U+1161 is 2, and so is 2 + 0.
jamo      L V T LV LVT
#
# ambiguous: East_Asian_Width is Ambiguous. NOTE 19 takes one cell and
#   `doc/implementation-defined.md` records it; a library in an East Asian
#   locale takes two, and some take two in any locale.
#
#   **The ranges are here rather than a rule saying `one against two`**, and
#   the difference matters: a rule that excused every narrowing would excuse a
#   generator that turned every Wide code point into one cell, which is
#   precisely the transcription error this gate exists to find. So the class
#   is a property of the code point like the other three. Regenerate the
#   `mark` and `ambiguous` ranges together with
#
#       python3 tests/checks/wcwidth.py --write-classes
#
#   when the pinned Unicode version moves; it reads runtime/unicode/ucd, which
#   `runtime/unicode/fetch.py` puts there and which is not committed.
#
# filler: the two Hangul fillers, named because they fit no class -- their
#   break value is Other and their width is a decision about a character that
#   is drawn as nothing. Written out rather than given a rule, since a rule
#   over two code points is a rule that hides them.
filler    U+3164 U+FFA0
